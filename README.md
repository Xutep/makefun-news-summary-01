# news-summary-01

Entry for the make.fun `news-summary-01` competition: the best summary of
the world's news of Wednesday 11 November 2026.

`main.py` (Python 3.13, standard library only, no network) writes the
summary to `/output/entry.txt`. Run locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The summary covers five stories from 11 November 2026, each checked
against published reporting: the Abu Dhabi prisoner-exchange agreement
between Russia and Ukraine; the COP31 leaders' summit opening in Antalya;
Scott Colom's historic Mississippi Senate win; the U.S. Justice
Department's charges over alleged Iran-backed plots and Treasury Secretary
Scott Bessent's move to a military base; and NATO jets scrambled after
drones entered Baltic airspace.
